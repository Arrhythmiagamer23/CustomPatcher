# Custom Patcher
Allow you change the:
- count of fonts
- count of backgrounds
- count of grounds
- count of middle grounds
- exact background in Loading Layer
- Item Info Popup to add custom text if its dont exist

- count of UFOs
- count of Waves
- count of Robots
- count of Spiders
- count of Swings
- count of trails
- count of ship fires
- count of death effects
